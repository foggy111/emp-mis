EMP 员工管理 MIS

这是经典 SSM 后端。除登录、注册和本页外，接口需要会话中的 loginUser。测试账号 admin / 123456。

  • POST /login、POST /register
  • POST /emps 新增
  • PUT /emps 修改
  • DELETE /emps/{id} 删除
  • DELETE /emps 批量删除，请求体为编号数组
  • GET /emps/{id} 单条
  • GET /emps?name=&gender=&dept=&page=1&size=5 分页条件查询

请用 ApiFox 或同类工具调试。部署时把应用上下文设为 /，路径才与上面一致。
